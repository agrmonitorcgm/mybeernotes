# Пивной дневник

Личный дневник дегустаций пива для Android, а в дальнейшем — для iOS и общего
использования двумя людьми.

## Что уже работает

- добавление, редактирование, удаление и поиск записей;
- название, дата, страна с флагом, крепость, пивоварня и стиль;
- цена, место покупки и отметка «взял бы ещё»;
- рейтинг от 1 до 10 пивными кружками с шагом 0,5;
- теги вкуса, комментарий и фотография этикетки;
- локальное хранение без интернета;
- импорт и экспорт полной JSON-копии дневника.

## Структура

- `desktop/dist/index.html` — браузерная версия и общий интерфейс;
- `mobile/android` — Android-проект;
- `PROJECT.md` — требования, решения и текущий статус.

## Android

Откройте `mobile/android` в Android Studio и соберите APK через меню **Build**.
Также поддерживается сборка из терминала:

```bash
cd mobile/android
./gradlew assembleDebug
```

GitHub Actions проверяет Android-сборку при каждом изменении. Тег вида `v0.2.0`
создаёт GitHub Release с APK, если в настройках репозитория сохранён ключ подписи.

Для установки новых версий поверх старых все релизы должны быть подписаны одним
ключом. Ключ не хранится в Git и должен быть сохранён отдельно.

## iPhone

Веб-версия подготовлена как PWA. После публикации откройте её в Safari,
нажмите **Поделиться → На экран «Домой»**. Появится отдельная иконка, приложение
будет открываться без интерфейса браузера и сможет работать без интернета.

Обновления веб-версии публикуются автоматически после изменений в ветке `main`.
Пока записи хранятся отдельно на каждом устройстве; общая база появится на этапе
синхронизации.
