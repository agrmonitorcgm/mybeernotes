# Пивной дневник

Дата начала: 2026-09-07. Владелец: George.

## Цель
Приложение для Android и iOS: записывать выпитое пиво, оценивать и быстро находить предыдущие дегустации. В перспективе пользователь и его девушка видят добавления друг друга.

## Объём первой версии
Пока без синхронизации между клиентами. У каждого устройства собственный дневник, записи другого человека не видны. Работа с дневником должна быть доступна без интернета.

### Поля записи
| Поле | Требование |
| --- | --- |
| Название | Название пива, текст |
| Дата | Дата, когда пил |
| Страна производителя | Страна производства |
| Крепость | Число рядом со значком %, допускается дробное значение |
| Рейтинг | Пивные кружки от 1 до 10 включительно, шаг 0,5 |
| Вкус | Несколько предустановленных тегов |
| Комментарий | Текст, максимум 300 символов |
| Фото | Возможность прикрепить фотографию этикетки |

Теги: кислый, мягкий, цветочный, терпкий, крепкий, сладкий, хлебный, с горчинкой, хмельной, медовый, легкий, фруктовый, говно, ссанина, горький, жженый, карамельный.

«Сладкий» в исходном списке повторялся: оставлен один тег. Формулировки остальных тегов сохранены.

### Поиск
Поиск среди добавленных записей по названию пива. Рабочее решение: частичное совпадение без учёта регистра; пустой запрос показывает весь дневник.

## Предварительные решения для интерфейса
Это рабочие допущения, а не дополнительные требования пользователя.
- Главный экран: поиск, список дегустаций, кнопка добавления.
- Форма добавления и редактирования: все поля записи; дата по умолчанию сегодня.
- Карточка: полная запись и фотография; возможность исправить запись и удалить с подтверждением.
- Рейтинг отображать десятью пивными кружками и числом, например 7,5/10; пустая, половинная и полная кружка показывают шаг 0,5.
- Одно пиво можно добавить повторно в другую дату: запись представляет дегустацию.
- Название обязательно; дополнительные сведения и фото можно пропустить. Отсутствующую оценку не подменять нулём.
- Фото хранить вместе с локальными данными приложения, чтобы выбор из галереи не оставался временной ссылкой.

## Текущий статус
Созданы локальная браузерная версия и Android-приложение. Веб-исходник: desktop/dist/index.html; выдаваемый файл: beer-diary.html. Android-проект находится в mobile/android, пакет — com.george.beerdiary, версия — 0.1.0, минимальная версия системы — Android 8.0 (API 26), целевая — Android 15 (API 35). Android-оболочка загружает тот же интерфейс из локального asset, не запрашивает доступ в интернет и хранит записи в отдельном хранилище WebView. Выбор фотографий, импорт JSON и сохранение JSON-копии подключены к системным диалогам Android.

Тестовый Android APK собран локально штатными Android Build Tools 35.0.0, выровнен и подписан debug-сертификатом. Проверены пакет, версия, min/target SDK, наличие HTML и classes.dex, zipalign и подписи APK Signature Scheme v2/v3. Сборка повторно выполнена скриптом build-local.sh. Интерактивная проверка на физическом Android-устройстве ещё не проводилась. iOS-сборка и синхронизация пока не реализованы. Веб-версия не опубликована.

Ближайший шаг: опубликовать публичный GitHub-репозиторий и PWA, затем проверить Android APK и установку веб-приложения через Safari на iPhone. После замечаний — общий синхронизируемый дневник для двух пользователей.

## 2026-09-08: рейтинг пивными кружками
Актуальное оформление жёлто-белое. Звёзды заменены десятью иконками пивных кружек в форме и карточках: пустая = 0, заполненная снизу наполовину = 0,5, полная = 1 балл. Например, 7,5 — семь полных, одна половинная, две пустые. Шкала оценки остаётся от 1 до 10 с шагом 0,5; «Без оценки» сохраняется. Левая половина кнопки выбирает полбалла, правая — целый балл; стрелки клавиатуры меняют оценку на 0,5. Добавлена легенда трёх состояний. Формат данных не изменён.
