# Пивной дневник — Android

Нативная Android-оболочка приложения. Дневник работает полностью локально,
без доступа к интернету, хранит записи в WebView и поддерживает импорт/экспорт
JSON, а также выбор фотографии этикетки.

## Сборка в Android Studio

Откройте эту папку как проект, дождитесь синхронизации Gradle и выберите
**Build → Build App Bundle(s) / APK(s) → Build APK(s)**. Требуются JDK 17,
Android SDK Platform 35 и Build Tools 35.0.0.

## Локальная сборка без Gradle

Если Maven недоступен, APK можно собрать только средствами Android SDK:

```bash
export ANDROID_SDK_ROOT="$HOME/Library/Android/sdk"
./build-local.sh
```

Результат появится в `build/outputs/apk/debug/beer-diary-debug.apk`.

## Следующий этап: два пользователя и iOS

Одна кодовая база может работать в Android и iOS. Для синхронизации потребуется
серверная база, хранение фотографий и вход пользователей. Рекомендуемый сценарий:
один человек создаёт общий дневник, приложение показывает код приглашения,
второй вводит код, после чего оба видят записи с подписью автора.
